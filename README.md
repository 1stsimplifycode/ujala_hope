# Ujala Hope — Accessible Web Experience

A web project containing pages and supporting assets for an accessibility-oriented interface, including sign-language-related HamNoSys resources.

## Contents
- `index.html` — main page
- `donate.html` — donation-related page
- `hamnosys/`, `hamnosysData/` — sign-language-related resources
- `js/`, `images/` — scripts and visual assets

## View locally
Clone or download the project and open `index.html` in a browser. A local static server is recommended if the scripts load resources via requests.

## Recommended validation
- Confirm keyboard navigation and screen-reader support
- Validate sign-language content with appropriate users or domain experts
- Test forms and links
- Ensure donation information is accurate and secure

This README describes files visible in the repository and does not imply a validated production service.
